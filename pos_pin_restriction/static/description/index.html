POS PIN Dashboard Restriction

Secure your Point of Sale with Employee PIN

🔐 What does this module do?

This module requires employees to enter their PIN before accessing the POS Dashboard. It ensures that only authorized employees can view and manage their assigned POS configurations.

✅ Key Features

  • PIN-based authentication for POS Dashboard
  • Filter POS configurations per employee permissions
  • Seamless integration with pos_hr module
  • Clean and modern PIN entry screen
  • Compatible with Odoo 19

📦 Dependencies

This module depends on: point_of_sale, hr, pos_hr
